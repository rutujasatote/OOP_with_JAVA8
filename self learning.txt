For loop: Use when the number of iterations is known.
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}


While loop: Use when the number of iterations is not known in advance; the condition is checked first.
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}


Do-while loop: Use when the code must execute at least once, even if the condition is false.
int i = 1;
do {
    System.out.println(i);
    i++;
} while (i <= 5);

3). Understand variable scope in nested loops

- i is accessible in the outer loop and inner loop.

- Both variables become inaccessible outside their respective scopes.


4. Understand how objects are stored in memory: Stack vs Heap visualization
In Java, stack memory stores local variables and method calls, while heap memory stores objects and arrays.
Key Differences between Stack and Heap Memory
1. Storage: Stack stores local variables and method call information, whereas Heap stores objects and arrays.

2. Memory allocation: Stack memory is managed through method calls, whereas Heap memory is dynamically allocated for objects.

3. Lifetime: Stack memory for a method frame is released when the method returns, whereas Heap objects remain until they are no longer reachable and are reclaimed by garbage collection.

4. Thread access: Each thread has its own stack, whereas Heap memory is shared among threads.

5. Speed: Stack allocation is generally faster, whereas Heap allocation generally involves more overhead.

6. References: Local reference variables are stored in stack frames, while the objects they refer to are stored in Heap memory.

1. Interface-Based vs Class-Based Inheritance
- Class-based inheritance: A class inherits properties and methods from another class using extends.
- Interface-based inheritance: A class implements an interface using implements and provides implementations for its abstract methods.
- Java supports extending only one class, but a class can implement multiple interfaces.
- Class inheritance promotes code reuse, while interfaces support abstraction and multiple-type contracts.

2. Diamond Problem in Java
- The diamond problem occurs when a class inherits the same method from two parent classes, creating ambiguity about which implementation to use.
- Java avoids this problem by not allowing a class to extend multiple classes.
- With interfaces, a class can implement multiple interfaces with the same default method, but it must override that method to resolve the conflict.

1. Method Overriding Rules
- A child class provides its own implementation of a method inherited from the parent class.
- The method name and parameter list must be the same.
- The return type must be the same or covariant.
- The access modifier cannot be more restrictive than the parent method.
- private, static, and final methods cannot be overridden in the usual sense. Static methods are hidden, not overridden.
- Constructors cannot be overridden.
- The overridden method can throw the same or narrower checked exceptions, but not broader checked exceptions.

2. Covariant Return Types
- Covariant return types allow an overriding method to return a subclass of the return type declared in the parent method.
- This applies to reference types, not primitive types.
- The child method's return type must be the same as or a subtype of the parent's return type.

3. @Override Annotation
- @Override tells the compiler that a method is intended to override a parent-class method or implement an interface method.
- It helps detect mistakes, such as incorrect method names or parameter lists.
- It is optional, but recommended.
- If the method does not actually override or implement a method, the compiler reports an error.

10) Collections
1. Decide Which Collection to Use Based on Requirements
ArrayList: Use when storing ordered elements and allowing duplicates.
LinkedList: Use when frequent insertions and deletions are needed.
HashSet: Use when unique elements are required without guaranteed order.
HashMap: Use when storing key-value pairs and requiring fast lookup by key.
TreeMap: Use when key-value pairs must be sorted by keys.
PriorityQueue: Use when elements must be processed according to priority.


2. Internal Working of HashMap
Hashing: Converts a key into a hash value used to determine the bucket location.
Buckets: Storage locations inside the HashMap where key-value entries are stored.
Collision: Occurs when multiple keys map to the same bucket.
Collision Handling: Java HashMap handles collisions using linked lists and can convert a bucket into a balanced tree when certain conditions are met.
Key Equality: HashMap uses hashCode() to locate a bucket and equals() to identify matching keys.
Performance: Average lookup, insertion, and deletion are O(1), assuming a good hash distribution.

3. Iterator vs ListIterator
Iterator can traverse collections in the forward direction only.
ListIterator can traverse a List in both forward and backward directions.
Iterator works with collections such as ArrayList, LinkedList, and HashSet.
ListIterator works only with List implementations.
Iterator supports element removal during iteration.
ListIterator supports adding, removing, and replacing elements during iteration.
ListIterator also provides methods to access the next and previous element indexes.

4. Fail-Fast vs Fail-Safe Iterators
Fail-Fast: Usually throws ConcurrentModificationException if a collection is structurally modified outside the iterator during iteration.
Fail-Safe: A commonly used informal term for iterators that tolerate concurrent modifications, often through a snapshot or weakly consistent view.
Fail-Fast Example: ArrayList, HashMap.
Concurrent-Modification-Tolerant Examples: CopyOnWriteArrayList uses a snapshot iterator; ConcurrentHashMap provides weakly consistent iterators.
Fail-Fast: Usually detects unexpected modifications rather than guaranteeing thread safety.
Snapshot Iterator: Iterates over a copy of the collection's state and may not reflect later changes.
Important: Fail-fast behavior is best-effort, and not every concurrent modification necessarily produces an exception.

11) Functional Programming
1. Method References
Method references are a shorter way to refer to an existing method using the :: operator.
They are commonly used with lambda expressions and functional interfaces.
Types of Method References
Static Method Reference: Refers to a static method of a class. Example: Integer::parseInt
Instance Method Reference: Refers to an instance method of a particular object. Example: System.out::println
Constructor Reference: Refers to a constructor to create objects. Example: Student::new

2. Effectively Final Variables in Lambdas
A variable is effectively final if its value is assigned once and never changed afterward.
Local variables used inside lambda expressions must be final or effectively final.
The variable cannot be reassigned after being captured by a lambda.
Instance and static fields do not have this restriction.
Example: int n = 10; list.forEach(x -> System.out.println(x + n));
3. Streams in Java
Streams process collections of data using operations such as filter(), map(), and sorted().
Streams do not store data; they process data from a source.
A stream pipeline generally consists of a source, intermediate operations, and a terminal operation.
4. Lazy Evaluation
Intermediate stream operations are executed only when a terminal operation is invoked.
Examples of intermediate operations: filter(), map(), sorted().
Examples of terminal operations: forEach(), collect(), count().
Lazy evaluation avoids unnecessary processing when results are not requested.

5. Stateless vs Stateful Operations
Stateless Operations: Process each element independently without needing information from other elements.
Examples: filter(), map().
Stateful Operations: May need information about multiple elements or the entire input before producing results.
Examples: sorted(), distinct().
Stateful operations may require additional memory or processing.

6. Short-Circuit Operations
Short-circuit operations stop processing as soon as the required result is determined, where possible.
Short-Circuit Intermediate Operations: limit(), takeWhile().
Short-Circuit Terminal Operations: anyMatch(), allMatch(), noneMatch(), findFirst(), findAny().
They can improve performance by avoiding unnecessary processing.
Example: list.stream().anyMatch(n -> n > 10) returns true as soon as a matching element is found.

12) JDBC
1. SQL Injection Prevention Using Parameterized Queries
SQL injection is an attack where malicious SQL code is inserted into user input.
Parameterized queries prevent SQL injection by separating SQL commands from user-supplied values.
Use PreparedStatement in Java instead of building SQL queries using string concatenation.
Example: PreparedStatement ps = con.prepareStatement("SELECT * FROM users WHERE id = ?");
Set the value using ps.setInt(1, id);.
Never directly concatenate untrusted input into SQL queries.

2. Stored Procedures vs Functions
Stored Procedure: A set of SQL statements stored in the database and executed using CALL in MySQL.
Function: A stored program that returns a value and can be used in SQL expressions.
Procedures can return results through result sets and output parameters.
Functions return a value using RETURN.
Procedures are generally used for performing operations or business processes.
Functions are generally used for calculations and returning values.

3. Optimistic vs Pessimistic Locking
Optimistic Locking: Assumes conflicts are uncommon and checks for changes before updating data.
It commonly uses a version number or timestamp to detect conflicting updates.
It is suitable when simultaneous updates are rare.
Pessimistic Locking: Locks data before modifying it to prevent conflicting transactions.
It commonly uses database locking mechanisms such as SELECT ... FOR UPDATE.
It is suitable when conflicts are frequent and data consistency is critical.

4. Connection Pooling
Connection pooling maintains a reusable collection of database connections.
Connections are borrowed when needed and returned to the pool after use.
It reduces the overhead of repeatedly creating and closing database connections.
It improves application performance and resource management.
Examples of Java connection pools include HikariCP and Apache Commons DBCP.
In pooled applications, closing a connection usually returns it to the pool rather than physically closing it.

5. Transaction Management
A transaction is a group of database operations treated as one logical unit.
A transaction is completed using COMMIT or cancelled using ROLLBACK.
Transactions help maintain data consistency when multiple operations are related.
ACID Properties
Atomicity: All operations in a transaction succeed, or none of them are applied.
Consistency: A transaction preserves database rules and constraints.
Isolation: Concurrent transactions are controlled to prevent improper interference.
Durability: Once committed, changes persist even after a system failure, subject to the database's durability guarantees.

Commit and Rollback
COMMIT: Permanently saves the changes made by the current transaction.
ROLLBACK: Undoes uncommitted changes made in the current transaction.
In JDBC, con.setAutoCommit(false) enables manual transaction control.
Use con.commit() to save the transaction.
Use con.rollback() to undo uncommitted changes.
Example: In a bank transfer, debit and credit operations should both succeed; if either fails, roll back the transaction.

3) Pascal's Triangle

import java.util.Scanner;

public class PascalsTriangle {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter number of rows: ");
        int n = sc.nextInt();

        int[][] a = new int[n][n];

        for (int i = 0; i < n; i++) {
            for (int j = 0; j <= i; j++) {
                if (j == 0 || j == i) {
                    a[i][j] = 1;
                } else {
                    a[i][j] = a[i - 1][j - 1]
                            + a[i - 1][j];
                }
            }
        }

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n - i - 1; j++) {
                System.out.print(" ");
            }

            for (int j = 0; j <= i; j++) {
                System.out.print(a[i][j] + " ");
            }

            System.out.println();
        }

        sc.close();
    }
}

import java.util.Scanner;
import java.util.Arrays;

public class BubbleSort {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter number of elements: ");
        int n = sc.nextInt();

        int[] arr = new int[n];

        System.out.println("Enter array elements:");
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - 1 - i; j++) {
                if (arr[j] > arr[j + 1]) {
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }

        System.out.println("Sorted array: " + Arrays.toString(arr));

        sc.close();
    }
}

import java.util.Scanner;
import java.util.Arrays;

public class SelectionSort {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter number of elements: ");
        int n = sc.nextInt();

        int[] arr = new int[n];

        System.out.println("Enter array elements:");
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        for (int i = 0; i < n - 1; i++) {
            int min = i;

            for (int j = i + 1; j < n; j++) {
                if (arr[j] < arr[min]) {
                    min = j;
                }
            }

            int temp = arr[i];
            arr[i] = arr[min];
            arr[min] = temp;
        }

        System.out.println("Sorted array: " + Arrays.toString(arr));

        sc.close();
    }
}

import java.util.Scanner;

class Student {
    int rollNo;
    String name;
    String course;
    double marks;

    
    Student(int rollNo, String name, String course, double marks) {
        this.rollNo = rollNo;
        this.name = name;
        this.course = course;
        this.marks = marks;
    }

    
    void display() {
        System.out.println("Roll No: " + rollNo);
        System.out.println("Name: " + name);
        System.out.println("Course: " + course);
        System.out.println("Marks: " + marks);
        System.out.println("--------------------");
    }

    
    Student(Student s) {
        this.rollNo = s.rollNo;
        this.name = s.name;
        this.course = s.course;
        this.marks = s.marks;
    }
}

public class StudentInformationSystem {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        Student[] students = new Student[100];
        int count = 0;
        int choice;

        do {
            System.out.println("\n1. Add Student");
            System.out.println("2. Display All Students");
            System.out.println("3. Search Student");
            System.out.println("4. Copy Student");
            System.out.println("5. Exit");
            System.out.print("Enter your choice: ");
            choice = sc.nextInt();
            sc.nextLine();

            switch (choice) {
                case 1:
                    System.out.print("Enter roll number: ");
                    int rollNo = sc.nextInt();
                    sc.nextLine();

                    System.out.print("Enter name: ");
                    String name = sc.nextLine();

                    System.out.print("Enter course: ");
                    String course = sc.nextLine();

                    System.out.print("Enter marks: ");
                    double marks = sc.nextDouble();
                    sc.nextLine();

                    students[count] =
                        new Student(rollNo, name, course, marks);
                    count++;

                    System.out.println("Student added successfully.");
                    break;

                case 2:
                    if (count == 0) {
                        System.out.println("No student records found.");
                    } else {
                        for (int i = 0; i < count; i++) {
                            students[i].display();
                        }
                    }
                    break;

                case 3:
                    System.out.print("Enter roll number to search: ");
                    int searchRoll = sc.nextInt();

                    boolean found = false;

                    for (int i = 0; i < count; i++) {
                        if (students[i].rollNo == searchRoll) {
                            students[i].display();
                            found = true;
                            break;
                        }
                    }

                    if (!found) {
                        System.out.println("Student not found.");
                    }
                    break;

                case 4:
                    System.out.print("Enter roll number to copy: ");
                    int copyRoll = sc.nextInt();

                    boolean copied = false;

                    for (int i = 0; i < count; i++) {
                        if (students[i].rollNo == copyRoll) {
                            if (count < students.length) {
                                students[count] =
                                    new Student(students[i]);
                                count++;
                                System.out.println(
                                    "Student record copied successfully."
                                );
                            } else {
                                System.out.println("Student storage is full.");
                            }
                            copied = true;
                            break;
                        }
                    }

                    if (!copied) {
                        System.out.println("Student not found.");
                    }
                    break;

                case 5:
                    System.out.println("Exiting program.");
                    break;

                default:
                    System.out.println("Invalid choice.");
            }

        } while (choice != 5);

        sc.close();
    }
}

import java.util.Scanner;

interface Notifiable {
    void sendNotification(String message);

    default void showStatus() {
        System.out.println("Notification service is ready.");
    }

    static void displayInfo() {
        System.out.println("Notification System");
    }
}

class Email implements Notifiable {
    String emailAddress;

    Email(String emailAddress) {
        this.emailAddress = emailAddress;
    }

    Email() {
        this.emailAddress = "default@gmail.com";
    }

    @Override
    public void sendNotification(String message) {
        System.out.println("Sending Email to: " + emailAddress);
        System.out.println("Message: " + message);
    }
}

class SMS implements Notifiable {
    String phoneNumber;

    SMS(String phoneNumber) {
        this.phoneNumber = phoneNumber;
    }

    @Override
    public void sendNotification(String message) {
        System.out.println("Sending SMS to: " + phoneNumber);
        System.out.println("Message: " + message);
    }
}

class Push implements Notifiable {
    String deviceName;

    Push(String deviceName) {
        this.deviceName = deviceName;
    }

    @Override
    public void sendNotification(String message) {
        System.out.println("Sending Push Notification to: " + deviceName);
        System.out.println("Message: " + message);
    }
}

public class NotificationSystem {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        Notifiable.displayInfo();

        System.out.println("1. Email Notification");
        System.out.println("2. SMS Notification");
        System.out.println("3. Push Notification");
        System.out.print("Enter your choice: ");
        int choice = sc.nextInt();
        sc.nextLine();

        System.out.print("Enter notification message: ");
        String message = sc.nextLine();

        Notifiable notification;

        switch (choice) {
            case 1:
                System.out.print("Enter email address: ");
                String email = sc.nextLine();
                notification = new Email(email);
                break;

            case 2:
                System.out.print("Enter phone number: ");
                String phone = sc.nextLine();
                notification = new SMS(phone);
                break;

            case 3:
                System.out.print("Enter device name: ");
                String device = sc.nextLine();
                notification = new Push(device);
                break;

            default:
                System.out.println("Invalid choice.");
                sc.close();
                return;
        }

        notification.showStatus();
        notification.sendNotification(message);

        sc.close();
    }
}

    @Override
    double calculateVolume() {
        return 0;
    }
}

abstract class ThreeD extends Shape {
    @Override
    double calculateVolume() {
        return 0;
    }
}

class Circle extends TwoD {
    double radius;

    Circle(double radius) {
        this.radius = radius;
    }

    @Override
    double calculateArea() {
        return Math.PI * radius * radius;
    }
}

class Rectangle extends TwoD {
    double length, breadth;

    Rectangle(double length, double breadth) {
        this.length = length;
        this.breadth = breadth;
    }

    @Override
    double calculateArea() {
        return length * breadth;
    }
}

class Sphere extends ThreeD {
    double radius;

    Sphere(double radius) {
        this.radius = radius;
    }

    @Override
    double calculateArea() {
        return 4 * Math.PI * radius * radius;
    }

    @Override
    double calculateVolume() {
        return (4.0 / 3) * Math.PI * radius * radius * radius;
    }
}

class Cube extends ThreeD {
    double side;

    Cube(double side) {
        this.side = side;
    }

    @Override
    double calculateArea() {
        return 6 * side * side;
    }

    @Override
    double calculateVolume() {
        return side * side * side;
    }
}

public class ShapeDemo {
    public static void main(String[] args) {
        Circle c = new Circle(5);
        Rectangle r = new Rectangle(4, 6);
        Sphere s = new Sphere(3);
        Cube cb = new Cube(4);

        System.out.println("Circle Area: " + c.calculateArea());
        System.out.println("Rectangle Area: " + r.calculateArea());
        System.out.println("Sphere Surface Area: " + s.calculateArea());
        System.out.println("Sphere Volume: " + s.calculateVolume());
        System.out.println("Cube Surface Area: " + cb.calculateArea());
        System.out.println("Cube Volume: " + cb.calculateVolume());
    }
}

10) Custom exception hierarchy

import java.util.Scanner;

class OrderException extends Exception {
    OrderException(String message) {
        super(message);
    }
}

class PaymentException extends OrderException {
    PaymentException(String message) {
        super(message);
    }
}

class InventoryException extends OrderException {
    InventoryException(String message) {
        super(message);
    }
}

class ShippingException extends OrderException {
    ShippingException(String message) {
        super(message);
    }
}

public class OrderManagement {
    static void makePayment(double amount) throws PaymentException {
        if (amount <= 0) {
            throw new PaymentException("Invalid payment amount.");
        }
        System.out.println("Payment successful.");
    }

    static void checkInventory(int quantity) throws InventoryException {
        if (quantity <= 0) {
            throw new InventoryException("Invalid product quantity.");
        }

        if (quantity > 10) {
            throw new InventoryException("Product is out of stock.");
        }

        System.out.println("Inventory available.");
    }

    static void shipOrder(String address) throws ShippingException {
        if (address == null || address.trim().isEmpty()) {
            throw new ShippingException("Invalid shipping address.");
        }

        System.out.println("Order shipped successfully.");
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        try {
            System.out.print("Enter payment amount: ");
            double amount = sc.nextDouble();

            System.out.print("Enter product quantity: ");
            int quantity = sc.nextInt();
            sc.nextLine();

            System.out.print("Enter shipping address: ");
            String address = sc.nextLine();

            makePayment(amount);
            checkInventory(quantity);
            shipOrder(address);

        } catch (PaymentException e) {
            System.out.println("Payment Error: " + e.getMessage());

        } catch (InventoryException e) {
            System.out.println("Inventory Error: " + e.getMessage());

        } catch (ShippingException e) {
            System.out.println("Shipping Error: " + e.getMessage());

        } finally {
            sc.close();
        }
    }
}

import java.util.HashMap;
import java.util.ArrayList;
import java.util.Scanner;

public class ShoppingCartSystem {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        HashMap<String, Double> products = new HashMap<>();
        ArrayList<String> orderHistory = new ArrayList<>();
        HashMap<String, Integer> cart = new HashMap<>();

        products.put("Laptop", 50000.0);
        products.put("Mobile", 20000.0);
        products.put("Headphones", 1500.0);
        products.put("Keyboard", 1000.0);
        products.put("Mouse", 500.0);

        int choice;

        do {
            System.out.println("\n1. Display Products");
            System.out.println("2. Add Product to Cart");
            System.out.println("3. View Cart");
            System.out.println("4. Place Order");
            System.out.println("5. View Order History");
            System.out.println("6. Exit");
            System.out.print("Enter your choice: ");
            choice = sc.nextInt();
            sc.nextLine();

            switch (choice) {
                case 1:
                    System.out.println("\nAvailable Products:");

                    for (String name : products.keySet()) {
                        System.out.println(name + " - Rs. " + products.get(name));
                    }
                    break;

                case 2:
                    System.out.print("Enter product name: ");
                    String name = sc.nextLine();

                    if (products.containsKey(name)) {
                        System.out.print("Enter quantity: ");
                        int quantity = sc.nextInt();
                        sc.nextLine();

                        if (quantity > 0) {
                            cart.put(name, cart.getOrDefault(name, 0) + quantity);
                            System.out.println("Product added to cart.");
                        } else {
                            System.out.println("Quantity must be greater than zero.");
                        }
                    } else {
                        System.out.println("Product not found.");
                    }
                    break;

                case 3:
                    if (cart.isEmpty()) {
                        System.out.println("Cart is empty.");
                    } else {
                        double total = 0;

                        System.out.println("\nYour Cart:");

                        for (String product : cart.keySet()) {
                            double price = products.get(product);
                            int quantity = cart.get(product);
                            double subtotal = price * quantity;

                            System.out.println(product + " x " + quantity
                                    + " = Rs. " + subtotal);

                            total += subtotal;
                        }

                        System.out.println("Total Amount: Rs. " + total);
                    }
                    break;

                case 4:
                    if (cart.isEmpty()) {
                        System.out.println("Cart is empty. Add products first.");
                    } else {
                        double total = 0;
                        StringBuilder order = new StringBuilder();

                        for (String product : cart.keySet()) {
                            int quantity = cart.get(product);
                            double subtotal = products.get(product) * quantity;
                            total += subtotal;

                            order.append(product)
                                 .append(" x ")
                                 .append(quantity)
                                 .append(", ");
                        }

                        order.append("Total = Rs. ").append(total);
                        orderHistory.add(order.toString());

                        System.out.println("Order placed successfully.");
                        System.out.println("Total Amount: Rs. " + total);

                        cart.clear();
                    }
                    break;

                case 5:
                    if (orderHistory.isEmpty()) {
                        System.out.println("No order history available.");
                    } else {
                        System.out.println("\nOrder History:");

                        for (int i = 0; i < orderHistory.size(); i++) {
                            System.out.println((i + 1) + ". " + orderHistory.get(i));
                        }
                    }
                    break;

                case 6:
                    System.out.println("Exiting Shopping Cart System.");
                    break;

                default:
                    System.out.println("Invalid choice.");
            }

        } while (choice != 6);

        sc.close();
    }
}

import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;
import java.util.stream.Collectors;

class Product {
    int id;
    String name;
    double price;
    int quantity;

    Product(int id, String name, double price, int quantity) {
        this.id = id;
        this.name = name;
        this.price = price;
        this.quantity = quantity;
    }

    public String toString() {
        return "ID: " + id + ", Name: " + name
                + ", Price: " + price + ", Quantity: " + quantity;
    }
}

public class ProductInventorySystem {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        List<Product> products = new ArrayList<>();

        products.add(new Product(101, "Laptop", 50000, 5));
        products.add(new Product(102, "Mouse", 500, 20));
        products.add(new Product(103, "Keyboard", 1500, 10));
        products.add(new Product(104, "Mobile", 20000, 8));
        products.add(new Product(105, "Headphones", 2500, 15));

        int choice;

        do {
            System.out.println("\n1. Display All Products");
            System.out.println("2. Add Product");
            System.out.println("3. Filter Products by Price");
            System.out.println("4. Display Product Names");
            System.out.println("5. Filter Products by Quantity");
            System.out.println("6. Exit");
            System.out.print("Enter your choice: ");

            choice = sc.nextInt();
            sc.nextLine();

            switch (choice) {
                case 1:
                    products.forEach(System.out::println);
                    break;

                case 2:
                    System.out.print("Enter product ID: ");
                    int id = sc.nextInt();
                    sc.nextLine();

                    System.out.print("Enter product name: ");
                    String name = sc.nextLine();

                    System.out.print("Enter price: ");
                    double price = sc.nextDouble();

                    System.out.print("Enter quantity: ");
                    int quantity = sc.nextInt();
                    sc.nextLine();

                    products.add(new Product(id, name, price, quantity));
                    System.out.println("Product added successfully.");
                    break;

                case 3:
                    System.out.print("Enter maximum price: ");
                    double maxPrice = sc.nextDouble();
                    sc.nextLine();

                    List<Product> filteredProducts = products.stream()
                            .filter(p -> p.price <= maxPrice)
                            .collect(Collectors.toList());

                    filteredProducts.forEach(System.out::println);
                    break;

                case 4:
                    List<String> productNames = products.stream()
                            .map(p -> p.name)
                            .collect(Collectors.toList());

                    System.out.println(productNames);
                    break;

                case 5:
                    System.out.print("Enter minimum quantity: ");
                    int minQuantity = sc.nextInt();
                    sc.nextLine();

                    List<Product> availableProducts = products.stream()
                            .filter(p -> p.quantity >= minQuantity)
                            .collect(Collectors.toList());

                    availableProducts.forEach(System.out::println);
                    break;

                case 6:
                    System.out.println("Exiting Product Inventory System.");
                    break;

                default:
                    System.out.println("Invalid choice.");
            }

        } while (choice != 6);

        sc.close();
    }
}
